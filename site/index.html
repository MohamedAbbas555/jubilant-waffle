Co-op Apply

A co-op job assistant for University of Waterloo students. It finds postings on WaterlooWorks and company websites, ranks them against your resume, writes tailored cover letters and fills in the applications.

This page is just information - the app runs on your own computer.

It signs in to WaterlooWorks through your own browser window (with Duo), keeps your resume and cover letters in a folder on your computer, and uses your own Anthropic API key. None of that can happen on a website, so there is nothing to sign in to here.

What it does

Finds jobsWaterlooWorks postings, plus co-op postings on the career sites of the top companies in your field.
Ranks themClaude scores each posting 0-100 against your resume, with reasons and gaps.
Writes cover lettersFrom any posting or a pasted job description. Preview, ask for changes, proofread.
AppliesFills WaterlooWorks packages and company application forms. Auto-apply can do it hands-off.

Get it (Windows)

  1. Install Python from python.org - tick "Add python.exe to PATH".
  2. Download the code: open the GitHub repository, click Code → Download ZIP and unzip it. (If the repository is private, you need to be given access first.)
  3. Double-click setup.bat once.
  4. Double-click Start Co-op Apply.bat whenever you want to use it. The app opens in your browser.

Mac or Linux: pip install -e ., playwright install chromium, then coop-apply gui.

Good to know

  • You need an Anthropic API key (console.anthropic.com). A full search + ranking run costs a few dollars.
  • Check the WaterlooWorks and Co-operative Education rules before automating applications, and read your cover letters.
